# GestDesp — Sistema de Gestão para Despachantes

Sistema web completo para gestão empresarial de despachantes.

## Funcionalidades

- Gestão de processos
- Cadastro de clientes e veículos
- Financeiro e relatórios
- Agenda e prazos
- Notificações
- Controle de usuários com perfis (Super Admin, Administrador, Funcionário)
- Assinatura e planos

## Tecnologias

- React 18 + TypeScript
- Vite
- Supabase (banco de dados + autenticação)
- TailwindCSS + shadcn/ui
- React Router

## Como rodar localmente

```sh
npm install
npm run dev
```
